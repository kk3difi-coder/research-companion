# Research Companion

Build an interactive web research and scraping application. Let users enter a domain, topic, date range, and keywords; retrieve and display relevant links ranked with a confidence/relevance percentage; generate an easy-to-read synthesis with key highlights and topic-related images; include a chatbot for follow-up questions and refining the topic; and save searches, sources, summaries, and chat history for future reference. Enable Lovable Cloud first for persistent data and backend capabilities. Use Firecrawl for search/scraping and Lovable AI for summaries and chat, with clear empty/loading/error states and a polished research-workspace UI.

This project was built with [Lovable](https://lovable.dev).
